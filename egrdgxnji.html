Keyboard shortcuts: (Press F1 to toggle)

  • Ctrl + Enter: Submit the blog post
  • Escape: Clear all inputs
  • Enter: In title input, move to content input; in content input, add a new line
  • F1: Toggle this help message
  • F2: Focus title input
  • F3: Focus content input
  • F4: Focus tags input
  • F6: Focus important tags dropdown

  • Ctrl + B: Bold
  • Ctrl + I: Italic
  • Ctrl + U: Underline
  • Ctrl + S: Strikethrough
  • Ctrl + H: Heading
  • Ctrl + L: Unordered list
  • Ctrl + Shift + L: Ordered list
  • Ctrl + Q: Blockquote
  • Ctrl + E: Code block
  • Ctrl + M: Insert image
  • Ctrl + K: Insert link
