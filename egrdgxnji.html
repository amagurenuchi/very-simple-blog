Shortcuts & Help

Navigation:

  • Ctrl + Shift + W / Alt + W: Open writing page from anywhere
  • Ctrl + Enter: Submit / Publish blog post
  • Ctrl + S: Save draft manually
  • F1: Toggle this Help popup
  • F11: Toggle Zen Focus mode
  • F2: Focus Title input
  • F3: Focus Content input
  • F4: Focus Tags input
  • Escape: Clear canvas or exit modal

Formatting Shortcuts:

  • Ctrl + B: Bold
  • Ctrl + I: Italic
  • Ctrl + U: Underline
  • Ctrl + S: Strikethrough (when in editor)
  • Ctrl + H: Heading
  • Ctrl + L: Bullet List
  • Ctrl + Shift + L: Numbered List
  • Ctrl + Q: Quote
  • Ctrl + E: Code block
  • Ctrl + K: Insert Link
  • Ctrl + M: Upload Image
  • Ctrl + V: Paste screenshot directly to upload to ImgBB
